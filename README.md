# J-M-Removal

Website project for J&M Removal in Houston.

## Current status

Planning and design preview. No production website has been deployed from this repository yet.

## Planned setup

- Custom domain: jandmremoval.com
- Hosting: Cloudflare Workers Static Assets
- Website source and version history: this GitHub repository
- Estimate requests: the existing Tally form at https://tally.so/r/QoMoPA
- Design: mostly white, with the existing J&M logo and deep-red brand accents

Only public website content, assets and maintenance instructions belong in this repository. Customer records, private uploads and credentials stay outside it.
